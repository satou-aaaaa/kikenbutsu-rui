# 危険物の類あて（kikenbutsu-rui）

物質の名前（品名）や性質の説明を読んで、消防法の危険物の第一類〜第六類のどれかを当てる1日5問の学習ゲーム。正解したら、その類の物品が固体か液体か（固体・液体・固体または液体）も選ぶ。中学・高校の理科や、暮らしの安全の学習に。

遊ぶ: <https://satou-aaaaa.github.io/kikenbutsu-rui/>

- 中身は e-Gov 法令検索の消防法 別表第一（<https://laws.e-gov.go.jp/law/323AC1000000186>）の類別・性質・品名と備考に書いてあることだけです。
- 説明は条文を短く言いかえたものです。指定数量や、政令・省令で決める試験の細かい決まりは省いています。公式の情報の代わりではありません。実際の物の扱い方・しまい方は、製品の表示や安全データシート、消防署の案内で確かめてください。危険物取扱者の試験の対策の代わりにもしません。
- 固体か液体かは、別表第一の備考の「固体であつて」「液体であつて」「固体又は液体であつて」で分けています。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
